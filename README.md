## 🚀 ដំណើរការនៅលើ Local (Local Development)

```bash
# ១. ដំឡើង Dependencies
npm install

# ២. កំណត់ឯកសារ .env
cp .env.example .env

# ៣. ចាប់ផ្តើមដំណើរការ
npm start
```
បើកកម្មវិធីរុករក (Browser)៖ [http://localhost:3000](http://localhost:3000)

## 🌐 ការដាក់ឱ្យដំណើរការ ២៤ ម៉ោងលើ Cloud (24/7 Hosting)

ប្រព័ន្ធនេះត្រូវបានរៀបចំឯកសារ `Dockerfile` និង `render.yaml` រួចជាស្រេចសម្រាប់ Deploy លើ Cloud Hosting (Render, Railway, Fly.io, ឬ Vercel):

### Deploy លើ Render.com (ឥតគិតថ្លៃ & 24/7):
1. Push កូដឡើងទៅកាន់ GitHub Repository
2. ចូលទៅកាន់ [Render.com](https://render.com) ➔ ជ្រើសរើស **New Web Service**
3. ភ្ជាប់ជាមួយ GitHub Repository
4. បញ្ចូល Environment Variables តាម `.env.example`
5. ចុច **Deploy** ជាការស្រេច!
